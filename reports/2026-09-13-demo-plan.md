# Demo plan — showing KuantorFlow to an English teacher

**Target: before the end of next week.** Written 13 September 2026.

This is two documents in one: the **runbook** for the day, and the **work plan** for the week before it. The ranking rule throughout is #331's — judge by what the audience will notice, not by engineering value. They teach English for a living; they will spot bad English faster than anyone else you could show this to, and they will not notice the architecture at all.

**There is no known correctness blocker.** Both demo blockers are closed — #231 (Oxford missing `can` and `do`) on 28 August, #258 (*Real or fake* marking a right answer wrong) on 30 August. So this week is not about building. It is about making sure nothing is embarrassing and nothing fails silently.

The keyword gate stays on. You hand them the keyword, and #199 — the one true launch blocker — blocks nothing here.

### What to actually show a teacher

Ranked for this audience, from #339's audit:

1. **Generate a text, then the worksheet** (#237 / #340). This week's vocabulary becomes a reading passage with the words marked, and then a printable gap-fill exercise. It is lesson *preparation*, not a game — the one feature a teacher would use even if their students never touched the site.
2. **A round URL is already a homework assignment.** `/games/spell_it/play?topic=Health&topic=Crime` is a real, shareable link, because the picker is a plain GET form (#250). Paste it into a class chat and it *is* the homework. Nobody has ever called it that out loud; it needs no code, only saying.
3. **One deck, ten activities.** The core classroom need: one vocabulary set, drilled ten ways, without re-entering the words per exercise type. Most tools make you rebuild the list for each activity.
4. **Notes upload** (`.mht` / `.docx` / `.txt`). Their existing word list becomes a deck without typing it in.
5. **Mykola**, last. He is the thing that impresses and the thing most likely to wobble; lead with the lesson material, not the AI.

### Say plainly what is not there yet

A teacher will ask within five minutes: *can I see how my students are doing?* The honest answer is no — nothing in the app records how anybody performed (#338 is the foundation and is not built), and there is no teacher/student relationship at all (#339). Saying so early is better than being asked.

## Part 2 — The work plan for the week

In order, cheapest and highest-value first. Each item stops for a decision before the next one starts.

### 1. Verify the worksheet's print layout (#340) — *no code unless it is broken*

The printable worksheet is the strongest single artefact for this audience, and **nobody has ever pressed Ctrl+P on it.** Screen rendering was measured at three viewport sizes; the page break was not. A 400-word text with 40 blanks is the real test.

Verified with headless Chrome, which is how the last print layout here was checked. If the layout holds, this ends with a sentence and no PR. If a blank splits across a page, it is a small CSS fix.

### 2. #99 + #19 — one branch, two commits, one PR

Deliberately breaking the one-ticket-per-PR habit: both are small, both are demo-facing, and it means one review and one deploy rather than two.

- **#99 — say so when the API credits run out.** Turns the demo's most likely silent failure into a sentence on the screen.
- **#19 — a tip above *Look up & save*.** Your teachers are first-time users, and nothing on the front page currently says what to do first.

### 3. #75, then the rest of the popup polish — *only if tokens allow*

#75 is one number, it demonstrably affects more than the ticket claims, and fixing it lets two existing workarounds be deleted. Then #208, #84, #120, #227 if there is room. #331's line on these is right: individually trivial, together they are the difference between "a project" and "a product".

### 4. #147 — the `General` topic — *look before building*

It holds the earliest, messiest cards, including misspelled headwords like `dist'inct` and `quirki`, and a teacher browsing the deck will find them. But #407 consolidated the topics and #414 changed the default, so check what is actually in production first. **Hiding it for the demo may beat fixing it.**
